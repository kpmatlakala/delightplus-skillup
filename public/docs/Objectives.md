# Project Objectives — CET Connect Platform

## Vision
Build a flexible learning delivery platform that supports both fully accredited courses and special-case interventions delivered by training providers (e.g., DSA).

## Primary Goals
- Support "Courses" as standalone accredited programmes with full module content, assessments, and PoE.
- Support "Interventions" as curated or tailored deliveries assembled from one or more Courses (e.g., CET SP derived from SAQA-78965 content).
- Provide a unified content authoring approach: source content in `public/docs/Courses_Actual/` and interventions in `public/docs/Interventions/`.
- Ensure exam/assessment content is canonical: author source-of-truth in markdown under `public/docs` and consume it in-app.
- Make assessments secure, auditable, accessible, and mobile-friendly.

## Immediate Objectives (near-term priorities)
1. Align Block 2 assessment content across: in-app questions, markdown paper, and memorandum.
2. Ensure in-app figure assets (e.g., `B2-FigA.png`) render correctly for each section.
3. Harden assessment-submission flows: reliable file uploads, friendly errors, draft autosave, and navigation guards.
4. Maintain clear repository docs so mission context is preserved when chat history is lost.
