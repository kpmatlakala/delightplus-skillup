## Station Tasks and Evidence

## Station 1: Programming and Design (14918, 14915, 14910) - 30 Marks

**CET Context:** Student mark processing system

| Task | Group Activity | Individual Accountability |
| --- | --- | --- |
| 1.1 | Write pseudocode to classify mark as Pass (>= 50) or Fail (< 50). | Each learner writes own pseudocode version. |
| 1.2 | Desk-check pseudocode using sample mark = 45 and complete trace. | Each learner records one desk-check step in personal log. |
| 1.3 | Label flowchart symbols: Start, Process, Decision, End. | Each learner labels one symbol on personal copy. |
| 1.4 | List 3 procedural programming features and 1 modularity benefit. | Each learner writes one feature and one benefit. |

**Group Output:** Pseudocode sheet + trace log + labeled flowchart + features list  
**Individual Output:** Personal pseudocode + desk-check step + symbol label + feature note

## Station 2: Systems Analysis and Hardware (14924, 14921, 14933) - 25 Marks

**CET Context:** Lab booking system design

| Task | Group Activity | Individual Accountability |
| --- | --- | --- |
| 2.1 | Label DFD components: External Entity, Process, Data Flow, Data Store. | Each learner labels one component on personal copy. |
| 2.2 | Match hardware types: PC, Server, Mainframe, Client-Server. | Each learner completes one matching pair. |
| 2.3 | Label web architecture: Client, Server, Database, Internet. | Each learner labels one architecture element. |
| 2.4 | List 3 information-gathering techniques and one CET advantage each. | Each learner records one technique + advantage. |

**Group Output:** DFD + hardware matching + web architecture + techniques list  
**Individual Output:** Personal labels + one hardware match + one technique note

## Station 3: Problem-Solving and Support (14927, 14919, 14908) - 25 Marks

**CET Context:** Student registration error resolution

| Task | Group Activity | Individual Accountability |
| --- | --- | --- |
| 3.1 | Complete fishbone for registration delays (People, Process, Environment). | Each learner contributes one cause on personal copy. |
| 3.2 | Draft support ticket: Problem, Steps taken, Resolution. | Each learner writes one ticket section. |
| 3.3 | List 5 problem-solving steps in order with one action each. | Each learner writes one step + action. |
| 3.4 | Choose one test stage (FAT/UAT/Site Testing) and justify choice. | Each learner writes one-sentence justification. |

**Group Output:** Fishbone + support ticket + cycle list + test-stage justification  
**Individual Output:** Personal cause + ticket section + step-action + justification

## Station 4: Teamwork and Service Leadership (14920, 118028) - 20 Marks

**CET Context:** Project team conflict over deadlines

| Task | Group Activity | Individual Accountability |
| --- | --- | --- |
| 4.1 | Role-play conflict scenario and write 3 resolution steps. | Each learner writes one resolution step. |
| 4.2 | Label team structure: Leader, Member, Task, Communication. | Each learner labels one part on personal copy. |
| 4.3 | List 3 customer service standards and one monitoring method each. | Each learner writes one standard + monitoring method. |
| 4.4 | Explain 2 benefits of teamwork in CET project context. | Each learner writes one benefit. |

**Group Output:** Conflict plan + team diagram + standards list + benefits list  
**Individual Output:** Personal resolution step + diagram label + standard note + benefit note
