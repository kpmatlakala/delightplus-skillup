## The Impact of Information Technology

**Information Technology (IT)** is the combination of hardware and software products and services that companies use to manage, access, communicate, and share information. IT can mean the difference between business success and failure.

### Three Forces Shaping the Future of IT

- **Changes in the world** — globalisation, digital transformation, and the demand for real-time information access
- **Changes in technology** — faster processors, cloud computing, AI, mobile platforms, and exponential data growth
- **Changes in client demand** — users expect faster, more intuitive, more secure and accessible systems

### Need for Systems Analysis and Design

Installing a system without proper planning leads to user dissatisfaction and frequently causes the system to fall into disuse. **Systems Analysis and Design (SA&D)** is a step-by-step process for developing high-quality information systems that lend structure to the analysis and design of business solutions.

## Roles of the Systems Analyst

A systems analyst plans, develops, and maintains information systems. They must work with people of all descriptions and be experienced with computers.

### Three Primary Roles

| Role | Description |
|---|---|
| **Consultant** | Works as an outside expert hired to address a specific business problem or need |
| **Supporting Expert** | Provides internal specialist assistance; advises on IT capabilities without owning the project |
| **Agent of Change** | Facilitates and drives organisational transformation; helps people, processes and systems adapt |

### Four Qualities of an Effective Systems Analyst

- **Problem solver** — breaks complex problems into manageable parts and develops practical solutions
- **Communicator** — translates technical concepts for users and business requirements for developers
- **Strong personal and professional ethics** — handles sensitive data and information with integrity
- **Self-disciplined and self-motivated** — manages time effectively and drives tasks to completion

## Information System Components

A **system** is a set of related components that produces specific results. A **mission-critical system** is one that is vital to a company’s operations. Information systems have five key components:

| Component | Description |
|---|---|
| **Hardware** | The physical layer of the information system. Moore’s Law: processing power roughly doubles every two years |
| **Software** | System software (OS, utilities), Application software (specific tasks), Enterprise applications (organisation-wide). May be horizontal (generic), vertical (industry-specific), or legacy (old but still in use) |
| **Data** | Tables store data; linked tables work together to supply information. Data = raw facts; Information = data transformed into useful output |
| **Processes** | Tasks and business functions performed by users, managers, and IT staff to achieve specific results |
| **People** | Stakeholders, users, and end users who interact with or are affected by the system |

## Systems Development Life Cycle (SDLC)

The SDLC is a phased approach to solving business problems through a specific cycle of analyst and user activities. Each phase has unique activities and outputs.

### The Seven SDLC Phases

| Phase | Activity | Output |
|---|---|---|
| **1. Identifying Problems, Opportunities and Objectives** | Interview user management; summarise knowledge; estimate project scope | Feasibility report with problem definition and objectives |
| **2. Determining Human Information Requirements** | Interviews, questionnaires, sampling, observation, prototyping | Understanding of user work, business functions, people, goals, data and procedures |
| **3. Analysing System Needs** | Create DFDs, activity/sequence diagrams; complete data dictionary; analyse structured decisions | Recommendation on what should be done |
| **4. Designing the Recommended System** | Design data-entry procedures, human-computer interface, controls, database/files, backup | Model of the actual system |
| **5. Developing and Documenting Software** | Develop original software; work with users on documentation; programmers code and test | Computer programs and system documentation |
| **6. Testing and Maintaining the System** | Test the system; perform maintenance; update documentation | Updated programs, identified problems, updated documentation |
| **7. Implementing and Evaluating the System** | Train users; plan conversion; review and evaluate system | Trained personnel and installed system |

## Systems Development Tools and Approaches

### Prototyping

**Prototyping** speeds up the development process by building an early working version of the system. Important decisions may be made too early, but prototypes are extremely valuable for validating requirements.

### CASE Tools (Computer-Aided Software Engineering)

**CASE tools** are productivity tools for systems analysts that automate routine work. They can generate program code (speeding implementation), improve analyst-user communication, and integrate life cycle activities.

### Object-Oriented (OO) Systems Analysis and Design

An alternate approach to structured SDLC. Analysis is performed on a small part of the system, followed by design and implementation. The cycle repeats until the project is complete. Examines the system as a collection of objects.

### Agile Methods

- Newest development approach; emphasises continuous feedback and iterative development
- The Agile community published the **Agile Manifesto**
- Two examples: **Scrum** and **Extreme Programming (XP)**
- Uses spiral model; process determines the end result; analysts must understand pros and cons before selecting

### Other Development Methods

| Method | Description |
|---|---|
| **JAD** (Joint Application Development) | Team-based; key users participate; results in more accurate requirements and stronger commitment |
| **RAD** (Rapid Application Development) | Speeds development through prototyping and user involvement in every phase |
| **RUP** (Rational Unified Process) | Enterprise-scale iterative framework with four phases |
| **MSF** (Microsoft Solutions Framework) | Flexible, scalable framework used in Microsoft environments |
