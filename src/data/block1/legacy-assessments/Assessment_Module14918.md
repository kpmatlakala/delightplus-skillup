# Module 14918 Assessment Plan

## Workbook (Formative)

### Session 1: Describe Principles of Computer Programming
**Learning Outcomes:**
- Describes problem analysis and program design techniques
- Identifies common data types (integer, real, string, boolean)
- Explains algorithm structures (sequence, selection, iteration) using pseudocode
- Applies documentation and quality assurance principles to simple programs

**Activities:**
| Activity | Question Description | Mark |
|----------|---------------------|------|
| 1        | List and explain the steps in the program maintenance cycle | 6    |
| 2        | Write pseudocode for a given simple problem | 10   |
| 3        | Identify and distinguish between at least three data types | 6    |
| 4        | Explain and apply arithmetic and logical operators | 6    |
| 5        | Describe the three algorithmic control structures with examples | 8    |
| 6        | Identify at least three program documentation and QA principles | 6    |
| 7        | Distinguish between validation and verification with examples | 8    |

## Extra Assessment Items (Simple English)

- Why should you plan before you start coding?
- Find and fix the mistake in this pseudocode: "Print the sum of two numbers, but forget to add them."
- Write simple pseudocode to add three numbers and show the answer.
- Name one rule for checking your code to make sure it works.

## Quiz Bank (Optional)

- Which of these is a data type in programming?
- What does a flowchart help you do?
- Which control structure repeats steps?
- What is the difference between checking and testing your code?
