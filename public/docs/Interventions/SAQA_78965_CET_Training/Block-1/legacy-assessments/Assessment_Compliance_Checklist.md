# Assessment Compliance Checklist (ETQA/MICT SETA)

## 1. Delivery Mode
- [ ] Assessment available online (platform-hosted)
- [ ] Printable PDF fallback provided for offline completion
- [ ] Submission options: upload, email, USB
- [ ] Evidence collected for PoE (Portfolio of Evidence)

## 2. Question Types
- [ ] Knowledge (theory, concepts)
- [ ] Practical (applied tasks, scenarios)
- [ ] Evidence-based (workbook, artefacts)
- [ ] All questions mapped to unit standard outcomes

## 3. Marking Rubrics
- [ ] Rubric/memo provided for each unit standard
- [ ] Marking criteria align with SAQA/MICT SETA requirements
- [ ] Feedback and assessor report completed
- [ ] Moderation checklist filled

## 4. Authentication & Integrity
- [ ] Declaration of authenticity signed by learner
- [ ] Plagiarism check performed
- [ ] Only blue/black pen accepted for physical evidence
- [ ] No correction fluid (tippex) used

## 5. Moderation & Reporting
- [ ] Assessor report completed
- [ ] Moderator report completed
- [ ] Evidence summary sheets filled
- [ ] All assessments mapped to unit standard criteria

## 6. ETQA/MICT SETA Requirements
- [ ] Provider accredited by ETQA/MICT SETA
- [ ] Assessment instruments integrate core, fundamental, elective standards
- [ ] Validity, reliability, authenticity, sufficiency checked
- [ ] Appeals procedure available

---

*Use this checklist for every assessment cycle to ensure full compliance.*
