# Docs Directory

This directory contains supporting documentation, lecture notes, and reference materials for all courses and interventions on the platform.

## Structure

- `Lectures/` — Lecture notes and teaching resources
- `Interventions/` — Skills programmes and short courses
- `SAQA_78965_CET_Training/` — Example: extracted content for a specific qualification/intervention
- Other supporting docs as needed

## Usage

- Use this directory to store any reference, compliance, or teaching materials that support the delivery of courses and interventions.
- Keep documentation organized by topic, course, or intervention for easy access and reuse.
