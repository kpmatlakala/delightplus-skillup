# Module 14915 Assessment Plan

## Workbook (Formative)

### Session 1: Design a Computer Program to Specification
**Learning Outcomes:**
- Applies structured program design techniques
- Demonstrates understanding of procedural programming features
- Documents program designs using appropriate development tools
- Applies maintenance and logical flow principles

**Activities:**
| Activity | Question Description | Mark |
|----------|---------------------|------|
| 1        | Identify and explain key architecture considerations for a given application type | 7    |
| 2        | Draw a decision tree for a given business rule scenario | 8    |
| 3        | Create a sequence diagram for a simple interaction | 8    |
| 4        | Determine batch or online processing suitability for two scenarios | 7    |
| 5        | Identify syntax errors in a code snippet using a syntax checker | 8    |
| 6        | Write a user-defined function in pseudocode | 10   |
| 7        | List and explain the stages of the program maintenance cycle | 7    |
| 8        | Desk-check a given design output and document all errors found | 10   |
| 9        | Explain the difference between desk-checking and compiling | 5    |

## Extra Assessment Items (Simple English)

- Why should you check your program design before you start coding?
- Draw a simple decision tree for a rule: "If a student passes, give a certificate. If not, give feedback."
- Write a short plan for a program that helps teachers record marks.
- Name one thing you learned about designing programs that will help you next time.

## Quiz Bank (Optional)

- What does a decision tree help you do?
- Which tool checks for mistakes in your code?
- What is the difference between batch and online processing?
- What are the steps to keep a program working well?
