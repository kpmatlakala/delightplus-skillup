## Workbook (Formative)

### Session 1: Apply Problem-Solving Strategies
**Learning Outcomes:**
- Defines and analyses workplace problems
- Evaluates possible solutions against set criteria
- Implements and monitors solutions effectively

**Activities:**
| Activity | Question Description | Mark |
|----------|---------------------|------|

| 2        | Create a process map for a given CET administrative scenario | 8    |
| 3        | Identify contributing factors using a fishbone diagram | 7    |
| 4        | Evaluate two alternative solutions against the SFF matrix | 8    |

| 6        | Create an implementation plan with timeline and resources | 10   |

## Extra Assessment Items (Simple English)

- Why should you understand a problem before you try to fix it?
- Draw a fishbone diagram for a problem at school (like late homework).
- Use a table to compare two ways to fix a problem. Which is better and why?
- Name one thing you will do differently next time you solve a problem.

## Quiz Bank (Optional)

- What is the first step in solving a problem?
- Which tool helps you find the real cause of a problem?
- What does SFF mean when choosing a solution?
- Why do you need a plan to fix a problem?
