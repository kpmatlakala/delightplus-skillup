# Cross-course Resources

Material that isn't tied to a single course — shared templates, policies and
how-to guides surfaced from the learner portal's **Resources** area.

```
resources/
├── templates/   # PoE templates, CV templates, declaration forms
├── policies/    # Appeals, plagiarism, RPL, code of conduct
└── guides/      # "How to submit a PoE", "How to use the portal", etc.
```
