# Block 1 Assessment Guide

## Overview
Block 1 covers both knowledge and practical skills. Assessments include:
- Knowledge checks (objectives, concepts, theory)
- Practical tasks (algorithms, pseudocode, applied scenarios)
- Workbook activities (templates, diagrams, written answers)

## Assessment Types

### Knowledge
- Short questions on SDLC, roles, data types, control structures
- Explain concepts (e.g., difference between validation and verification)
- Describe steps in program maintenance cycle

### Practical
- Write simple pseudocode for a given problem
- Draw a decision tree or flowchart
- Desk-check a design output
- Group task: Stakeholder map, Team Charter, Program Design Document

### Workbook
- Complete workbook sections for each module
- Use provided templates (SDLC, team charter, fishbone diagram, structure diagram)
- Submit written answers and diagrams

## Sample Assessment Items

- **Knowledge:**
  - What are the phases of the SDLC?
  - List three data types and their uses.
  - Explain the role of an information systems analyst.

- **Practical:**
  - Write pseudocode for a login process.
  - Draw a decision tree for a business rule.
  - Develop a stakeholder map for a CET lab booking system.

- **Workbook:**
  - Complete the team charter template.
  - Fill in the fishbone diagram for a given problem.
  - Document program design using structure diagram template.

## Submission & Marking
- Submit workbook and practical tasks via portal
- Facilitator marks knowledge and practical items
- Group tasks assessed for participation and completeness
