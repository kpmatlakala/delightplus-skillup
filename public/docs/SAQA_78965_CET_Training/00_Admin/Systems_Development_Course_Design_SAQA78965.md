The primary goal of this training programme is to equip CET lecturers with practical systems development skills and ETQA-aligned assessment competence, enabling them to effectively supervise student projects and Work-Integrated Learning (WIL).

## **3.1 Component Breakdown Summary**

| **Component** | **Count** | **Total Credits** | **Strategic Rationale** |
| --- | --- | --- | --- |
| **Core (C)** | 7 standards | 41 credits | Mandatory technical backbone — non-negotiable for SAQA compliance and lecturer competency |
| **Elective (E)** | 3 standards | 19 credits | High-value practical skills (testing, support, teamwork) directly supporting WIL supervision and student mentorship |
| **Fundamental (F)** | 0 standards | 0 credits | Lecturers already possess NQF Level 3–4 communication/math competencies; focus retained on technical delivery skills |

## **3.2 Rationale for This Mix**

-   Compliance First: All 7 Core standards ensure the training meets the qualification's mandatory technical requirements.
-   Practical Edge: The 3 Electives (testing, user support, project teamwork) directly support lecturers in supervising WIL and student assessments.
-   Time-Efficient: Skipping Fundamental standards respects lecturers' existing NQF Level 3–4 competencies and keeps focus on new technical delivery skills.
-   Flexible Scaling: If CET later wants a full 165-credit rollout, this 10-standard module serves as a perfect technical core foundation.

*Recommendation: Maintain the 7 Core + 3 Elective mix. Fundamental standards (e.g., 119465, 9015) can be added later if CET explicitly requests coverage of communication or data literacy outcomes.*

# **5\. CAPSTONE PROJECT: LECTURER'S MINI-TOOLKIT**

## **Project Description**

A simple, offline-capable web-based application that helps CET lecturers manage and track teaching activities:

-   Log and track student project submissions
-   Generate templated, customisable feedback
-   Record and categorise common student technical issues
-   Export basic reports for moderation and WIL documentation

## **Why This Capstone Works**

| **Benefit** | **Explanation** |
| --- | --- |
| **Real-World Relevance** | Directly addresses daily pain points for CET lecturers in Venda |
| **Full Standards Coverage** | All 10 unit standards are naturally embedded in the build process |
| **Scalable Complexity** | Teams can start with a basic HTML form and progress to validated, tested, documented solutions |
| **PBL and Assessment Ready** | Demonstrates teamwork, iterative development, and produces tangible evidence for ETQA moderation |
| **Localisation Friendly** | UI copy and support docs can be produced in Sepedi/Tshivenda + English |

## **Team Deliverables**

-   Working Prototype: HTML/CSS/JS frontend + optional Python/Node backend (USB-deployable)
-   Design Document: Requirements spec, wireframes, architecture diagram, data model
-   Test Plan and Bug Log: Test cases, execution results, resolved issues
-   User Support Guide: Troubleshooting FAQ + contact protocol (bilingual Sepedi/English)
-   Portfolio of Evidence (PoE): Structured folder mapping all artefacts to the 10 unit standards
