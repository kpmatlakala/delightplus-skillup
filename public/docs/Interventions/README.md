# Interventions Directory

This directory contains all interventions, skills programmes, and short courses derived from the full qualifications in `Courses_Actual/`.

## Structure

- Each intervention is a markdown file or folder documenting:
  - Intervention name and description
  - Parent course(s) and referenced modules
  - Credit value and outcomes
  - Assessment and certification details

## Example

```
docs/Interventions/
  CET_Systems_Dev_Skills_Programme.md
  Digital_Literacy_Short_Programme.md
  ...
```

## Creating a New Intervention

1. Create a new markdown file for the intervention.
2. List the parent course(s) and included modules.
3. Document learning outcomes, credits, and assessment strategy.
