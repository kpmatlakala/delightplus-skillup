# **LESSON PLAN — 14910: Apply Programming Principles**

**Module:** ITSD-14910 | Block 2 | Days 6–7  
**Training Intervention:** CET Lecturers Systems Development Training

## **Lesson Title- Applied Programming: Tools, Data and Code Structure**

## 

## **Lesson Overview**

This two-day module strengthens practical programming skills through hands-on tool usage, structured coding principles, data handling, and debugging techniques. Emphasis is placed on CET-relevant, offline-capable solutions.

## **Lesson Objectives**

By the end of this module, learners will be able to:

1.  Operate programming development tools (editor, syntax checker, compiler).
2.  Explain and apply different data representations in programs.
3.  Apply algorithmic structures using pseudocode.
4.  Use high-level programming concepts including modularity and debugging.  
    

## **Lesson Content**

### **Session 1: Programming Development Tools**

-   Role of text editors, syntax checkers, and compilers
-   Workflow for identifying and correcting syntax errors
-   Library functions vs user-defined functions
-   Practical compilation and execution process  
    

### **Session 2: Data Representation in Programs**

-   Numeric types: integers, real numbers, currency, percentages
-   Text and alphanumeric data, date/time formatting
-   Boolean values and logical operators (.AND., .OR., .NOT.)
-   Internal representation: ASCII, binary, memory structures  
    

### **Session 3: Core Programming Principles**

-   Algorithm structures: sequence, selection, iteration (pseudocode)
-   Documentation standards: commenting, readability, modularity
-   Quality assurance: validation vs verification, testing methods  
    

### **Session 4: High-Level Language Concepts**

-   Constants vs variables (scope and parameter passing)
-   Arithmetic, relational and logical operators
-   Modular programming: procedures, functions, reusability
-   Debugging methods: desk-checking, tracing, structured test data  
    

## **Facilitator Activities**

-   Mini-lecture: Translating pseudocode into Python.
-   Live demonstration of syntax checking and compilation (offline VS Code).
-   Guided debugging exercise (broken code snippets).
-   Group discussion: Impact of data types in CET student systems.
-   Hands-on coding: Develop a function to validate a student ID format.
-   Distribution of Code Quick-Start Toolkit (templates, testing checklist).
-   Peer code review session focusing on readability and error handling.

## **Learner Activities**

-   Activity 1: Define text editor and syntax; identify syntax errors.
-   Activity 2: Demonstrate use of development tools.
-   Activity 3: Explain internal data representation (ASCII, binary, memory).
-   Activity 4: Identify data types in sample programs.
-   Activity 5: Write pseudocode demonstrating sequence, selection and loop.
-   Activity 6: Explain documentation principles.
-   Activity 7: Distinguish constants and variables using CET examples.
-   Activity 8: Explain benefits of modular programming.
-   Activity 9: Define and apply debugging techniques.

## **Resources Required**

-   Offline development tools (VS Code + Python on USB)
-   Printed pseudocode cards and debugging checklist
-   Data type glossary and algorithm flowcharts
-   Whiteboard and markers
-   Bilingual glossary (Sepedi/Tshivenda terminology)
-   Backup printed activities (power failure contingency)
-   Sample debugging code snippets (CET-contextualised)
-   Facilitator and Learner Guides (SAQA 14910)

## **Assessment (Formative)**

-   Observation checklist (syntax accuracy and data identification)
-   Marked worksheets (Activities 1–9)
-   Peer feedback on pseudocode clarity
-   Exit reflection ticket
-   Evidence aligned to SAQA 14910 summative requirements  
    

**Duration:** 600 minutes (2 days × 5 hours)  
**Status:** Active

# **LESSON PLAN — 14933: Create Web Applications with Scripting**

**Module:** ITSD-14933 | Block 2 | Days 8–9  
**Training Intervention:** CET Lecturers Systems Development Training

## **Lesson Title - Web Scripting Foundations: HTML, CSS and JavaScript for CET Tools**

## 

## **Lesson Overview**

This module introduces learners to foundational web development skills required to create simple, secure, and compliant web applications suitable for CET environments, particularly offline-capable systems.

## **Lesson Objectives**

By the end of this module, learners will be able to:

1.  Analyse requirements for web-based applications.
2.  Compare rich client and browser-based user interface models.
3.  Demonstrate understanding of copyright and ownership considerations.
4.  Identify version control and security issues in web applications.  
    

## **Lesson Content**

### **Session 1: Web Application Requirements**

-   HTTP as a stateless protocol and design implications
-   Bandwidth constraints and performance considerations
-   Client environment considerations (latency, reliability, platform diversity)  
    

### **Session 2: User Interface Approaches**

-   Rich client applications: benefits and limitations
-   Browser-based applications: accessibility and trade-offs
-   Enhancing interactivity using HTML, CSS and JavaScript  
    

### **Session 3: Copyright and Ownership**

-   Fundamentals of copyright protection
-   Public domain and fair use principles
-   Attribution and ethical reuse of web resources
-   Code, media and linking considerations  
    

### **Session 4: Version Control and Security**

-   Version control principles (tracking, collaboration, rollback)
-   Security fundamentals: confidentiality, integrity, availability
-   Practical safeguards: input validation, authentication, HTTPS  
    

## 

## **Facilitator Activities**

-   Mini-lecture: Web architecture (Client → Server → Client).
-   Live coding demonstration: Build a styled HTML form with JavaScript validation.
-   Guided design activity: Create a CET lab booking form.
-   Group discussion: Copyright implications in sharing teaching resources.
-   Hands-on enhancement: Implement JavaScript validation.
-   Distribution of Web Quick-Start Toolkit (templates, compliance checklist).
-   Peer review of web forms focusing on usability and code quality.  
    

## **Learner Activities**

-   Activity 1: Define network protocol and compare TCP/IP and OSI models.
-   Activity 2: Explain bandwidth implications for web applications.
-   Activity 3: Compare rich client vs browser-based systems.
-   Activity 4: Identify copyright considerations in web development.
-   Activity 5: Design a CET web form using HTML and CSS.
-   Activity 6: Implement JavaScript validation for required fields.
-   Activity 7: Discuss ownership and royalty implications.
-   Activity 8: Identify web security risks and mitigation strategies.  
    

## **Resources Required**

-   Offline development tools (VS Code + HTML/CSS/JS templates)
-   Printed web development cheat sheets
-   Copyright and security checklists
-   Whiteboard and markers
-   Bilingual glossary
-   Backup printed activities (offline contingency)
-   Sample broken web forms for debugging practice  
    

## **Assessment (Formative)**

-   Observation checklist (form structure, validation implementation)
-   Submitted HTML/CSS/JS files and worksheets
-   Peer usability feedback
-   Exit reflection ticket
-   Evidence aligned to SAQA 14933 summative requirements  
    

**Duration:** 600 minutes (2 days × 5 hours)  
**Status:** Active
