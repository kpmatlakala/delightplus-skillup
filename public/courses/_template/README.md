# Course Template

Copy this entire folder to `public/courses/<course-slug>/` when onboarding a new
course. Replace placeholders in `course.json` and populate each subfolder.

```
<course-slug>/
├── course.json       # Qualification metadata (see template below)
├── workbooks/        # Learner workbooks (LW_<US>_LearnerWorkbook_<TAG>.pdf)
├── assessments/      # Summative + practical assessments (SA_<US>_…)
├── memos/            # Memoranda for workbooks and assessments
├── slides/           # Presentation decks (PDF or PPTX)
└── resources/        # Misc supporting docs (case studies, datasets, links)
```
